# Gestionale ReFrame — prototipo

Prototipo navigabile per validare l'esperienza del futuro gestionale commerciale e operativo di ReFrame Hub.

Include dati dimostrativi, navigazione responsive, simulazione dei diversi ruoli, pipeline commerciale, progetti, calendario, clienti, team, amministrazione e insight. Non è ancora collegato a un database; opportunità, ruolo selezionato e task completate vengono conservati localmente nel browser per rendere la demo testabile.

Per avviarlo in locale basta servire la cartella con un server statico, ad esempio `python3 -m http.server 4173`.
