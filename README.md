# Gestionale ReFrame — prototipo

Prototipo navigabile per validare l'esperienza del futuro gestionale commerciale e operativo di ReFrame Hub.

Include dati dimostrativi, navigazione responsive, simulazione dei diversi ruoli, pipeline commerciale, progetti, calendario, clienti, team, amministrazione e insight. Le entità sono collegate tra loro: task e calendario aprono la lavorazione corretta, opportunità e clienti hanno schede modificabili, i membri del team mostrano il lavoro assegnato e le azioni amministrative rimandano ai rispettivi progetti. Ogni progetto contiene un workspace operativo con fasi, task modificabili, checklist, responsabili, scadenze, commenti, allegati dimostrativi, timeline, file ed economia. Non è ancora collegato a un database; ruolo e modifiche vengono conservati localmente nel browser per rendere la demo testabile.

Per avviarlo in locale basta servire la cartella con un server statico, ad esempio `python3 -m http.server 4173`.
